Support

How can we help?

HingeFlow requires macOS 14 or later, a supported Apple silicon MacBook, and Screen Recording permission.

Quick help

  • If the effect does not start, open System Settings → Privacy & Security → Screen & System Audio Recording and enable HingeFlow.
  • If the lid sensor is unavailable, use Live Preview to test and customize the effect.
  • Press Escape or choose Stop Effect from the menu bar at any time.
